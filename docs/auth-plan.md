# 登录系统（已实现）

> 方案：邮箱 + 密码自建登录，PBKDF2 哈希，无第三方依赖。

## 数据模型

- `profiles` 表新增：`email`（唯一）、`password_hash`、`password_salt`
- 未登录 = guest（`email` 为空）；已登录 = 账号（`email` 非空）
- cookie（`guild_author`）即会话凭证：登录 = cookie 绑定账号 token；登出 = 轮换新 token

## 流程

- **注册**（`/login`）：邮箱唯一校验 → PBKDF2-SHA256（310k 迭代）→ 若当前是 guest 身份则原地升级为账号（资料保留），否则新建账号并换绑 cookie
- **登录**：查邮箱 → 验哈希 → 若当前是 guest 且发过帖子，帖子迁移合并到账号（`author_token/author_id` 更新为账号），删除 guest
- **登出**（`/me`）：cookie 轮换为新 guest token，账号保留
- guest 仍可完整使用（发布/编辑），登录仅是身份增强

## 已实现界面

- `/login`：登录/注册双卡片
- `/me`：登录状态（邮箱 + 登出 / 未登录 + 登录入口）
- Header：guest 显示「登录」+ 圆形占位头像；登录后显示头像

## 安全现状与后续

- 密码：PBKDF2-SHA256、随机 salt、不存明文 ✅
- 待办（后续里程碑）：
  - 登录失败限流（防暴力破解）
  - 修改密码 / 找回密码（需邮件服务，当前未接）
  - session 撤销（登出全部设备）
  - 注册邮箱需验证（防滥用）

## 测试记录

- 注册（大小写归一化）→ 重复邮箱拒绝 → 错误密码拒绝 → 正确登录
- guest 发帖 → 登录 → 帖子合并到账号且作者主页 URL 不变 → 登出（cookie 轮换）→ 再登录帖子仍在
